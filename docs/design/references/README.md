# Nook — Visual References

Store reference screenshots in subfolders such as:

```text
references/
├── landing/
├── auth/
├── app-shell/
├── dashboard/
├── jobs/
└── applications/
```

Screenshots are inspiration, not source-of-truth specifications.

For every reference worth keeping, document:

## Reference
Product/page name.

## What we like
The exact pattern or quality.

## What we do NOT copy
Brand identity, proprietary graphics, exact text, exact layout, or distinctive assets.

---

# Recommended Reference Map

## Linear

Use as inspiration for:
- app shell
- sidebar
- compact information density
- dark mode
- subtle interaction feedback
- command/productivity feel

Do not clone:
- Linear branding
- exact issue/task UI
- proprietary icons/assets

---

## Attio

Use as inspiration for:
- data-heavy views
- record pages
- tables
- detail panels
- workflows/agent surfaces

---

## Framer

Use as inspiration for:
- marketing motion
- hero storytelling
- scroll-based product reveals
- interactive product demonstrations

Keep this expressive motion mostly out of the authenticated dashboard.

---

## Clerk

Use as inspiration for:
- sign-in/sign-up hierarchy
- OAuth placement
- verification/reset flows
- form spacing

---

## Resend / Vercel

Use as inspiration for:
- visual restraint
- typography
- spacing
- border treatment
- simple CTA hierarchy

---

# Rule

When adding a screenshot, write down **what you want from it**.

Bad:

"Make Nook look like Linear."

Good:

"Use this reference for sidebar density, 1px neutral borders, subdued inactive items, and a strong but restrained active row. Keep Nook's typography, colors, routes, and brand."
