# Nook — Project Brief

## Product

Nook is an AI Career Operating System.

The user builds a structured Career Profile once. Nook then helps the user:

Discover
→ Understand
→ Match
→ Prepare
→ Validate
→ Apply
→ Track
→ Learn

## Core source of truth

Career Profile = trusted career facts.

Master resume = immutable input artifact.

Generated resume = versioned derived artifact.

Historical application = immutable snapshot of what was actually submitted.

## Initial product modes

- Manual application
- Assisted application
- Auto Apply only after strict safety/idempotency controls exist

## Product principles

- Never fabricate professional facts.
- Never guess sensitive application answers.
- Explain match scores.
- Keep users in control of automation.
- Make the product useful before autonomous applying exists.
