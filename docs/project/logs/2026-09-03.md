- **New migration `20260902192324_career_profile_schema`** (applied to

  - `project` extended: `role`, `start_date`, `end_date`, `source`, `updated_at`,
    date-order CHECK, **composite `UNIQUE (id, user_id)`**; `tech_stack` dropped.
  - `education` extended: `field_of_study`, `grade`, `description`, `source`,
    `updated_at`, date-order CHECK.

### Database / migrations

- 6 migrations total; 17 public tables; RLS enabled + policy-audited on all.
- Composite `(id, user_id)` FKs on every parent→child edge: `profile` →

  Phase 2 (architecture invariant 7 respected).
